# Bullpen Runtime Slides

This workspace is a standalone Next.js slide deck for the Bullpen / OpenClaw / Convex talk.

## Scripts

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the deck overview and `/slides` for the presentation player.

## Deck Structure

The presentation follows an 11-slide narrative:

1. Title
2. Who we are
3. From assistant to runtime
4. What did not work
5. What worked better
6. One orchestrator, many specialized workers
7. Why Convex fit
8. What changed for us
9. A short example
10. What we learned
11. Close

## Controls

- Right arrow / space: next reveal or slide
- Left arrow: previous reveal or slide
